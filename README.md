# AI News Digest Automation

## Overview
This project is an automated AI News Digest workflow built using n8n. It fetches the latest AI news, generates summaries using Gemini AI, stores the data in Google Sheets, and sends email notifications automatically.

## Features
- Automated AI news collection
- AI-powered article summarization using Gemini
- Google Sheets integration
- Automated email notifications
- Built entirely with n8n workflows

## Tech Stack
- n8n
- Gemini AI API
- Google Sheets API
- Gmail API

## Workflow
1. Fetch the latest AI news.
2. Generate summaries using Gemini AI.
3. Store the news data in Google Sheets.
4. Send an email digest automatically.
